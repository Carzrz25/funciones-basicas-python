## Descripción

Este repositorio contiene 8 Jupyter Notebooks donde se investigan y documentan **30 funciones básicas de Python** (*built-in functions*). Cada función incluye su descripción, sintaxis, parámetros y ejemplos prácticos con su resultado.

## Notebooks

| Notebook | Categoría | Funciones |
|---|---|---|
| [01_entrada_salida.ipynb](01_entrada_salida.ipynb) | Entrada y salida | `print`, `input` |
| [02_informacion_objetos.ipynb](02_informacion_objetos.ipynb) | Información de objetos | `len`, `type`, `isinstance` |
| [03_conversion_tipos.ipynb](03_conversion_tipos.ipynb) | Conversión de tipos | `int`, `float`, `str`, `bool` |
| [04_estructuras_datos.ipynb](04_estructuras_datos.ipynb) | Estructuras de datos | `list`, `tuple`, `dict`, `set` |
| [05_matematicas.ipynb](05_matematicas.ipynb) | Matemáticas | `abs`, `round`, `pow`, `divmod`, `sum`, `min`, `max` |
| [06_secuencias.ipynb](06_secuencias.ipynb) | Secuencias | `range`, `sorted`, `reversed`, `enumerate`, `zip` |
| [07_funcional.ipynb](07_funcional.ipynb) | Programación funcional | `map`, `filter`, `any`, `all` |
| [08_archivos.ipynb](08_archivos.ipynb) | Archivos | `open` |

## Cómo ver los notebooks

Haz clic en el nombre de cualquier notebook de la tabla. GitHub lo muestra directamente con las explicaciones, el código y los resultados.
